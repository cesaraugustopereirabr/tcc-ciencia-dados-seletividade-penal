# TCC - Ciência de Dados e Inteligência Artificial

## Autor

Cesar Augusto Pereira

## Tema

Análise da seletividade penal brasileira utilizando dados do SISDEPEN/SENAPPEN.

## Objetivo

Investigar a concentração do encarceramento em crimes patrimoniais, especialmente o furto, por meio de técnicas de Ciência de Dados.

## Estrutura

- dados/: base utilizada no estudo
- notebooks/: código e análises
- imagens/: gráficos e visualizações

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
